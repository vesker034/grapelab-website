# GrapeLab Website

Сайт лаборатории GrapeLab с административной частью и хранением данных через Prisma.

**Стек:** Next.js, React, TypeScript, Prisma, PostgreSQL, Docker Compose.

## Запуск

```bash
npm ci
npm run dev
```

Для локального запуска настройте переменные окружения и базу данных по схеме Prisma.
